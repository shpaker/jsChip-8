jsChip-8
========

Chip-8 interpreter written in JavaScript.

Live: http://shpaker.github.io/jsChip-8/

- Space Invaders starts automatically, any other ROM can be loaded via the file input
- CHIP-8 keypad is mapped to `1234` / `QWER` / `ASDF` / `ZXCV` (layout-independent), on-screen buttons work with mouse and touch
- Run locally: serve the folder with any static server, e.g. `python3 -m http.server`, and open `index.html`
- No sound yet
